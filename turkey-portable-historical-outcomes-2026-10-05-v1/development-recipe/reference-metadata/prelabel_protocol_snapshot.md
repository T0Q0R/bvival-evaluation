# Turkey v1：价格打开前的队列、分组与信息隔离协议

阶段：只冻结非价格队列与访问边界，不是完整模型预注册，不授权测试标签释放。
本协议在 schema/特征审计之后制定；已看到非价格分布和作者文档中的汇总价格/
模型成绩，没有解析本项目该来源个体价格。不得写成完全数据盲的预注册。
不回写旧三源的已打开测试，也不将本来源自动并入主稿结果。

## 准入与清理（执行前规则）

固定工作簿、源码提交和文件哈希沿用上一轮审计。复用已测试的 XLSX 选列
读取器，价格单元格和不准入列不进入值解析；不生成任何标签 CSV。
使用 Spreadsheets 的只读、敏感内容隔离路线，不整表导入或重存工作簿。

按固定配置 `experiments/configs/turkey_price_free_cohort_2026-09-30.json`：

- 字符串做 Unicode NFKC、空白合并和 casefold。空、横杠、nan/none/null/
  n/a/na 解释为缺失。没有目标编码或按价格合并类别。
- 品牌、车系、车款名称必须非空；车款仅用于属性分组，不进入模型输入。
- 年份必须为整数且在 1900–2026；里程有限非负且不超过 1,000,000 源单位。
  这是事先固定的数据质量边界，不是价格分位数。单位仍遵循来源字段语义，
  没有独立核验；结论须受此限制。
- 主队列要求三请求字段均有记录：合法里程、三类变速箱之一、五类燃油之一。
  因此只研究完整记录的人为隐藏/揭示，不证明对自然缺失/MNAR有效。
- 喷漆与更换部件数若为 0–30 内整数则保留，否则标记缺失，不因它排除整行。
  它们是已记录的初始信息，不是现场核验结果；零和缺失必须区分。
- 不按价格、预测误差或收益筛样本。价格缺失/非正/非有限的独立标签规则在
  后续完整分析计划中冻结，当前不能知道最终可评分 n；不设价格上分位数。

## 去重、分组与不独立性

`id` 是源顺序号，记录键由工作簿 SHA-256 与数据行序号产生。它仅定位固定
文件的记录，不称平台广告 ID、VIN 或车辆身份。

规范化十四个非价格属性（不含 id）的全属性指纹用于近似去重。每个指纹
只保留最小 SHA-256 记录键；不按价格挑代表。其余记录保留排除原因，原文件
不删除。这样仍可能误合并不同车辆，不能声称完成实体解析。

更粗的品牌/车系/车款/年份/里程指纹用于分组。相同粗指纹的保留记录必须
同分区；燃油/变速箱等不同的近似资料也不跨区。用固定 namespace 对组哈希
后取 first8 mod100：0–54 训练、55–69 验证、70–84 校准、85–99 测试。
训练组另用独立 namespace 分五个 OOF folds；同组全部增强状态同折。
不存在行级时间戳，不宣称时间外推。哈希分区百分比为期望比例而非精确配额。

这只能防止所定义的属性簇跨区，不能保证同车不同里程/文本的广告不跨区，
也没有卖家 ID 可控制卖家依赖。统计须同时报告 retained listing 数与属性组数，
不能把它们当经核实的独立车辆数量。

## 信息表边界

初始可见表只含品牌、车系、年份、车身、颜色、卖方类别、喷漆数量、更换数量。
完整车款文本、发动机排量/功率和顺序号不进入模型或策略。车系中的隐性线索
仍可能存在，应报告非价格别名扫描，不把排除车款称为已消灭一切代理信息。

里程、变速箱、燃油单独保存到 private acquisition-fields 表。它也没有价格，
但包含待揭示值，不能整张表拼进 pre-action 风险/收益策略输入。组哈希、
profile 哈希、记录键、原始定位序号只作连接/分区，不能作为预测特征。

初始表和请求表分别生成，测试标签没有被解析或导出；这不是安全隔离/加密
系统。生成的行级文件均为本地私有，不加入现有发布包。

## 后续分析计划需要固定的项目（尚不执行）

1. 主任务为三字段、每 listing 至多揭示一项、等成本容量 10%；5%/20% 曲线
   为次级诊断。它不是原四字段任务的完全同协议复制。
2. 强制模型/OOF 按属性组处理，所有初始/增强状态不跨 OOF；验证只调参，
   校准只做预声明校准，不用测试挑策略。
3. 主比较为 benefit allocation 与同目标 risk allocation；必须加验证集选定
   的最强固定字段和神经一阶段目标对照，不能拿 adaptation 冒充官方 GDFS。
   若方法训练预算/版本/实现身份尚未冻结，就不能称完整实验预注册。
4. 全队列的 post-reveal 挂牌价 MAE 为拟定主指标；2% 是实际意义参考，不是
   保证。主比较的点效应/区间须同时报告；CI 仅排除零不证明超过 2%。
5. 未来 bootstrap 按预定义属性组配对抽样，计算 listing 加权 MAE；组内记录
   同步抽样，种子不乘 n。固定拟合与固定分配的区间不包含重训/市场抽样误差。
   对照家族和多重比较规则须在测试释放前另外冻结。
6. 没有真正挂牌时间、成交价、卖家请求记录、实际审核成本、图像和碳标签。
   不宣称因果利润、响应率、视觉品相或全市场代表性。
