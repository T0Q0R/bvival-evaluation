# Turkey historical scoring and outcome companion

Version: `turkey-portable-historical-outcomes-2026-10-05-v1`.
This package is a **historical reconstruction**, not a new confirmation, a
renewed once-release authorization or an independent-machine result. It embeds
the byte-preserved development recipe and supplies the original path-read test
snapshot missing from that recipe's scoring closure. Never alter the original
development package, running workspace, ledger or historical evaluation files.

## What is provided and what is not

Code, original configurations/reference metadata, scoped software licensing,
both original aggregate evaluations and the unchanged development recipe are
included. No workbook, real rows, targets, predictions, actions, fitted models
or original access ledger are included. Source and main/neural runtime routes
are in `development-recipe/README.md`; source-specific terms still apply.

First run that embedded recipe through `--prepare`, `--readiness` and `--fit` in
a new private directory. It rebuilds source features and trains the complete
original 258/21/6 schedule. For scoring, **use this companion**, not its legacy
`--score`: the legacy package omitted `test_freeze_turkey_heldout_scores.py`,
which the original scorer reads as a snapshot rather than imports.

This companion keeps both package versions unchanged. It projects only the
freshly rebuilt non-price features/protected source code into a separate new
private output and adds that original test file. It references only models
generated by the verified reconstruction, not the author's old study models.
The entire score and allocation replay then uses the unchanged original code.

## Integrity and staged execution

```sh
python3 -I -B -S release-bvival/check_turkey_portable_outcomes.py --package-root .
```

The check imports no study code, reads no workbook cells and performs no fits.
It verifies the entire exact inventory, original helper hashes and embedded
development recipe. It does not establish empirical success.

For the companion's synthetic contract tests, use the main dependency runtime:
`python3 -m pytest -q -p no:cacheprovider release-bvival/tests/test_turkey_portable_outcomes.py`.
These checks do not read source prices or train study models.

```sh
python3 -I -B release-bvival/run_turkey_portable_outcomes.py \
  --package-root /absolute/path/to/this/companion \
  --development-workspace /absolute/path/to/completed-development \
  --output /absolute/path/to/new-private-companion-output --prepare
python3 -I -B release-bvival/run_turkey_portable_outcomes.py \
  --output /absolute/path/to/new-private-companion-output --score
python3 -I -B release-bvival/run_turkey_portable_outcomes.py \
  --output /absolute/path/to/new-private-companion-output --outcomes
```

Omit `--prepare` for read-only preflight. Completed readiness and **completed
full real fitting**, not a log/checkpoint/PID, are mandatory. Scoring binds both
entire feature partitions (7,814 calibration and 7,802 test), reloads policies,
retains all original budgets/policies/seeds, and reads no held-out prices.

`--outcomes` is a distinctly recorded **reread of already-evaluated historical
prices from the pinned original source**. It first reloads the three valuation
models twice and freezes all before/three-after predictions for BOTH complete
phases, verifying their before values against the frozen allocation contexts.
Only then does the original selected-cell reader decode the complete historical
phase targets; no allocation/fit/field selection is changed. The original
accounting correction is used; targets are not written to a price CSV.

The original pure evaluator is unchanged, including its two primary tests,
10,000 fixed bootstrap draws, Holm correction and conditional inference scope.
Its `authorized_heldout_only` internal input role denotes locally bound real
targets, **not a newly issued once-release receipt or new confirmation**. Both
full aggregate structures must match the original references within the
original `1e-12` numerical roundoff bound. Failure is retained, not retried with
a looser threshold. It is possible for integrity to pass while this comparison
fails; do not upgrade the capability flags until actual execution is checked.

## Boundaries

No original project root/cache/ledger is an input. The original ledger is neither
read nor written and the original release controller is not called. The old
v2 stages remain development-only/price-free; this separate historical contract
does not change their scope. The package does not touch the reserved AT cohort.
Source buffers physically contain prices; selective parsing is not an enclave
or independent label custody. Private outputs contain rows/models/predictions:
**do not upload the private execution trees**.

This closes a proposed Turkey execution route only after a real complete run.
It does not establish all-study portability, fresh installation on this run,
Q3 eligibility, real verification costs, profits or algorithm superiority.
