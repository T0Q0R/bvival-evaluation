# Historical core-comparator reconstruction companion

This local companion rebuilds two existing evidence families from artifacts
NEWLY GENERATED by the three source-directed primary recipes:

1. Joint mean benefit versus development-prior fixed-field mean benefit,
   including the original four policies, complete selections, MAEs, 10,000
   listing bootstraps and three-contrast nominal interval adjustment.
2. The original cached-neighbor diagnostic, all nine policies per source,
   all three neighbor scales (16/64/128), unchanged allocation and eligibility.

It is not a new analysis, new model comparison, independent confirmation or
full TAFA/ACO reproduction. No original row caches, raw rows, predictions,
models or selected listing IDs are included. Six aggregate reference JSONs
are included; machine-specific runtime information is removed from the fixed
config template and is supplied only when executing the private copy.

## Required precursor

Obtain and execute `historical-primary-reconstruction-2026-10-04-v2` as its
README directs, once per MUCars/JUCars/AutoScout24 source. The primary package's
manifest SHA256 is `fa2cef5b9009a2984db59548265c8f62dcbd7e6bba65f6f64e4ad06eb438d551`.
Keep the three completed PRIVATE copy directories. This companion verifies
their actual source-to-results receipts and all scoring/outcome artifact hashes;
it does not accept the original `experiments/outputs/` directory as a precursor.

Original source identifiers, units and access terms are given in the primary
README. Own-code licensing and external reviewer release are still pending.
This companion grants no software or data rights.

## Provenance and outputs

The unchanged diagnostic scripts expect historical relative directory names.
Only inside the NEW private tree, the controller supplies those names as
explicit aliases for regenerated CSVs. Reference audit JSONs come from the
primary metadata package; they are marked as historical metadata, not freshly
produced audit receipts. In particular, JUCars uses its newly generated legacy
projection CSV with the pinned legacy schema audit. Do not claim that this
recreates the omitted historical secondary-score join guard.

`input-alias-provenance.json` identifies every generated-row origin and every
historical metadata reference. Outputs are `fixed-results/`, `neighbor-results/`
and `comparator-reconstruction-receipt.json`. These contain private row-level
artifacts and MUST NOT be uploaded as the public companion package.

Acceptance is exact, not tolerance relaxation: all fixed scientific results,
intervals and selection-file hashes must match; all nine neighbor policy
results, scores and allocations must match. Only execution timestamps,
fixed-config/runner execution receipts and neighbor timing observations are
excluded from result comparison. Failure is retained without automatic retry,
tuning, source selection or threshold widening.

This covers the two named comparison families, not Turkey redevelopment,
GDFS training, all subgroup analyses, real inspection requests or operations.
Historical tests stay already opened. Rebuilt known comparisons provide
reproducibility evidence, not algorithm novelty or a journal-acceptance claim.
